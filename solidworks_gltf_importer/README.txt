Solidworks GLTF Importer (SWGI)

Install:
- Edit > Preferences > Add-ons > Install...
- Select the ZIP (do not unzip manually)
- Enable: "Solidworks GLTF Importer"

Updater (optional):
- Open Add-on Preferences
- Set 'Update Manifest URL' to a JSON file hosted online, eg:
  https://raw.githubusercontent.com/<you>/<repo>/main/swgi_manifest.json

Manifest example:
{
  "version": [2, 4, 1],
  "download_url": "https://github.com/<you>/<repo>/releases/download/v2.4.1/Solidworks_GLTF_Importer.zip",
  "notes": "Bug fixes"
}

Then:
- Click 'Check Updates'
- Click 'Install Update'
- Restart Blender
